# Lunar
# 🌙 Lunor / Explorf (Dashboard) **Современный и стильный WPF-дашборд на .NET с темной темой интерфейса, встроенным таймером фокуса, органайзером папок и умным календарем.**
--- ## ⚡ Основные возможности * **Элегантный UI/UX:** Полностью кастомизированная темная тема, бесшовная интеграция интерфейса и плавные интерактивные элементы управления. * **📂 Менеджер папок:** Быстрый доступ к рабочим директориям в один клик с возможностью гибкого выбора и автосохранением. * **⏱️ Фокус-таймер:** Настраиваемые пресеты (5, 10, 15 минут) и ручной ввод времени для продуктивной работы. * **📅 Интерактивный календарь:** Система цветовых меток дней и персональные заметки для каждого числа. * **📝 Ежедневные заметки:** Автоматическое сохранение записей для каждого дня недели. * **⏰ Живые часы:** Точное системное время и дата прямо в интерфейсе дашборда. --- ## 🛠️ Технологический стек * **Платформа:** .NET Framework / WPF * **Язык программирования:** C# * **Оформление:** XAML (Custom Window Styles, Templates) * **Сериализация:** `System.Text.Json` для надежного сохранения данных --- ## 🚀 Быстрый старт 1. Клонируйте репозиторий: ```bash git clone https://github.com/your-username/Explorf.git ``` 2. Откройте проект в **Visual Studio** (или VS Code с установленным расширением для .NET). 3. Убедитесь, что в проект добавлены необходимые сборки: * `System.Windows.Forms` 4. Соберите и запустите проект (`Ctrl + Shift + B`, затем `F5`). --- ## 💻 Использование * **Панель навигации слева:** Быстрое переключение между основным **Dashboard** и **Calendar & Notes**. * **Управление окном:** Кастомная шапка позволяет перетаскивать окно мышкой, сворачивать и закрывать приложение. * **Автосохранение:** Все добавленные папки, заметки и настройки календаря автоматически сохраняются в локальные файлы конфигурации при изменении. ---
